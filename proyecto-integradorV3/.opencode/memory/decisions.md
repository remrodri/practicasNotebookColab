# Decisiones vigentes

- Bronze permanece inmutable.
- Las mediciones físicas faltantes no se imputan sin evidencia suficiente.
- Las filas no resolubles se conservan en cuarentena con motivo.
- Gold conserva ventanas no evaluables con objetivo vacío.
- Un objetivo vacío no se convierte en clase 0.
- El EDA usa solo ventanas evaluables para gráficos del objetivo.
- Los grupos cercanos a -18 °C, 4 °C y 20 °C son descriptivos, no límites permitidos.
- El modelo oficial conserva las cinco predictoras mínimas.
- `producto_id` se usa para auditar desempeño, no como predictor oficial.
- El umbral 0,50 no se optimiza con prueba.
- Auditoría inicial y final deben quedar separadas.
- Última actualización: 2026-09-30.
