# Registro de auditorías

Guardar aquí las auditorías realizadas con las skills `andinalog-auditoria-inicial` y `andinalog-auditoria-final`.

Nombre recomendado:

- `AAAA-MM-DD-nbNN-auditoria-inicial.md`
- `AAAA-MM-DD-nbNN-auditoria-final.md`

Cada informe debe identificar alcance, evidencias, conteos, hallazgos por severidad, correcciones requeridas y veredicto. La auditoría inicial no modifica archivos; la final verifica las correcciones sobre evidencia nueva.
